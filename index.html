📥 Установить Пулю

Установите Пулю как приложение на рабочий стол Windows:

  1. Откройте сайт в браузере Chrome, Edge или Яндекс.
  2. В адресной строке справа найдите иконку ⊕ или 🖥️ «Установить» — кликните по ней.
  3. Либо: нажмите ⋮ (три точки) в правом верхнем углу → «Установить приложение».
  4. Введите название (например, Пуля) → «Установить».
  5. Иконка появится на рабочем столе и в меню «Пуск».
💡 Если в браузере нет кнопки установки — просто создайте ярлык: кликните правой кнопкой на пустом месте рабочего стола → «Создать» → «Ярлык» → вставьте ссылку на Пулю → «Далее» → назовите «Пуля» → «Готово».

Установите Пулю как приложение на телефон Android:

  1. Откройте сайт в браузере Chrome.
  2. Через пару секунд сверху появится баннер «Установить приложение» — нажмите на него.
  3. Либо вручную: нажмите ⋮ (три точки) в правом верхнем углу → «Установить приложение» или «Добавить на главный экран».
  4. Подтвердите установку.
  5. Иконка 🚀 Пуля появится на рабочем столе телефона и в меню приложений.
⚠️ Если пишет «это приложение нельзя установить» — включите «Версия для ПК» в меню Chrome, дождитесь перезагрузки страницы, и значок установки появится в адресной строке.

Установите Пулю как приложение на iPhone/iPad:

  1. Откройте сайт только в Safari (в Chrome на iPhone установка не работает).
  2. Нажмите кнопку «Поделиться» — это квадрат со стрелкой вверх внизу экрана (или сверху на iPad).
  3. Прокрутите меню вниз → выберите «На экран "Домой"».
  4. Введите название Пуля → нажмите «Добавить».
  5. Иконка 🚀 Пуля появится на домашнем экране iPhone.
💡 На iPhone приложение откроется в отдельном окне — без адресной строки, как обычное приложение.
